# مستطيل أخضر 🇩🇿⚽

نسخة أولى (MVP) لتطبيق Android مخصص للدوري الجزائري.

## الموجود حالياً
- واجهة رئيسية عربية RTL
- مباريات اليوم ببيانات تجريبية
- ترتيب الدوري ببيانات تجريبية
- تبويب المباريات والترتيب والأخبار
- تصميم أخضر/أبيض متجاوب
- بنية جاهزة لربط API حقيقي لاحقاً

## تشغيل المشروع
1. ثبّت Flutter.
2. افتح المجلد في Android Studio أو VS Code.
3. نفّذ:
   flutter pub get
   flutter run

## ربط البيانات الحقيقية
لا تضع API Key داخل التطبيق. الأفضل أن يمر التطبيق عبر Backend آمن.
مصادر مناسبة للدراسة: API-Sport / TheStatsAPI / Live-Football-API.
يجب مراجعة الترخيص والأسعار وتغطية الدوري الجزائري قبل اختيار المزود.

## الخطوة التالية
إضافة Backend + API حقيقي للمباريات والترتيب والأحداث المباشرة، ثم تجهيز AAB للنشر على Google Play.
